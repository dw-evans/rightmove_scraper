This application will send emails on your behalf including details of the latest rightmove listings.
You can hopefully see the listings early and get in for viewings. 

Follow these steps to use the app:

0. Configure the config.toml file
    a. Provide your email recipients (separated by comma)
    b. Adjust the filters (maxBedrooms, minBedrooms, maxPrice).
1. Run the rm-scaper exe file
2. Grant access for the api to send emails on behalf of your gmail account in the popup.
3. Leave the process running, it will ping rightmove and return new houses at a 60 second interval/
4. Keep the process running as long as you want it to search. It only notifies *new* listings.
